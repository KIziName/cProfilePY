## Python Profiler
A lightweight GUI wrapper for Python's built-in cProfile profiler, built with Tkinter.

## Features
- Select a Python script and pass command-line arguments

- Run profiling in a separate process (UI stays responsive)

- Display script stdout in real time

- Sort statistics by cumtime, time, calls, name, or nfl

- Adjustable row limit (5–100)

- Progress bar during execution

- Stop profiling with force‑kill option

- Copy full output (script stdout + statistics) to clipboard

- Clear both output panes

## Requirements

- ***Python 3.6+*** 
- When running from a compiled EXE, a Python interpreter

## Python Profiler
Графическая обёртка для встроенного профилировщика cProfile с интерфейсом на Tkinter.

## Возможности
- Выбор Python-скрипта и передача аргументов командной строки

- Запуск профилирования в отдельном процессе (интерфейс не блокируется)

- Отображение stdout профилируемого скрипта в реальном времени

- Автоматическая сортировка статистики по cumtime / time / calls / name / nfl

- Настраиваемое количество выводимых строк (5–100)

- Индикация выполнения (прогресс-бар)

- Остановка профилирования с принудительным завершением

- Копирование результата (вывод + статистика) в буфер обмена

- Очистка полей вывода

## Требования
- ***Python 3.6+*** 
- При скачивания EXE – требуется наличие интерпретатора Python
